# Задание 1. Разбор tsconfig.json

Откройте `tsconfig.json` в корне проекта и для каждой строки напишите
**своими словами**, что она делает. Не копируйте документацию —
объясните так, как будто рассказываете одногруппнику.

## compilerOptions

### target
> Версия JavaScript, в которую компилируется код (например, "ES5", "ES6")

### module
> Формат модулей ("CommonJS", "ESNext", "AMD" и др.)

### moduleResolution
> Определяет стратегию и алгоритм, по которому TypeScript ищет импортируемые модули (во внутренних папках проекта и в сторонних пакетах).

### strict
> Включает строгую проверку типов

### strictNullChecks
> Делает null и undefined отдельными типами и запрещает их присваивание переменным других типов без четкого указания

### esModuleInterop
> Обеспечивает совместимость между ES-модулями и CommonJS, позволяя импортировать CommonJS-библиотеки с помощью дефолтных импортов

### skipLibCheck
> Пропускает проверку типов во всех файлах деклараций (*.d.ts), что значительно ускоряет процесс компиляции

### forceConsistentCasingInFileNames
> Заставляет строго соблюдать регистр символов в путях импорта файлов, предотвращая проблемы при переносе кода между разными ОС

### outDir
> Каталог, куда помещаются скомпилированные .js файлы

### rootDir
> Путь к исходным файлам проекта

## include
> Указывает папки/файлы, которые включаются в процесс компиляции

## exclude
> Указывает папки/файлы, которые исключаются из компиляции

# Задание 1.2. Включение флагов

Для каждого пункта ниже:
1. Определите, какой флаг нужно поменять в `tsconfig.json`.
2. Внесите изменение.
3. Запустите `npm run check`.
4. Запишите результат в `task1.md`.

---

### 1. Строгие проверки типов
Включите опцию, которая делает `null` и `undefined` отдельными типами,
а не «совместимыми со всем». Без неё код с `null` компилируется, с ней — нет.

**Ваш ответ:** `strictNullChecks`

---

### 2. Проверка `this`
Включите опцию, которая ругается, если внутри функции используется `this`,
но функция не является методом класса (то есть `this` не определён).

**Ваш ответ:** `noImplicitThis`

---

### 3. Неявный `any`
Включите опцию, которая ругается, если переменная получает тип `any`
автоматически (например, функция без аннотаций параметров).

**Ваш ответ:** `noImplicitAny`

---

### 4. Возврат из функции
Включите опцию, которая требует, чтобы **все** ветки функции возвращали значение,
если функция объявлена как возвращающая не-`void`.

**Ваш ответ:** `noImplicitReturns`
